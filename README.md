# Deswik.CAD – AutoCAD Process Map

Process Map developed in Deswik.CAD to automate and standardize repetitive tasks related to the preparation of AutoCAD files.

The development was supported by ChatGPT as an AI copilot for logic structuring, troubleshooting and automation development.

## Current Functions

- Multiple DXF/DWG import
- Automatic layer organization
- Entity cleanup
- Layer deletion
- Layer consolidation

## Objective

Reduce repetitive manual tasks, standardize workflows and explore practical applications of Artificial Intelligence in Mine Planning.

## Tools

- Deswik.CAD
- AutoCAD / DXF-DWG
- ChatGPT
